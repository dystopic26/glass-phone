# Glass Phone

Releases of the Glass Phone desktop app (text, call, and audio-clip calls through Twilio).

**Download:** see [the latest release](https://github.com/dystopic26/glass-phone/releases/latest).

- Mac (Apple Silicon): `Glass-Phone-<version>-arm64.dmg`
- Mac (Intel): `Glass-Phone-<version>-x64.dmg`
- Windows: `Glass-Phone-Setup-<version>.exe`

Once installed, the app updates itself. Updates are signed; the app rejects anything without a valid signature.
